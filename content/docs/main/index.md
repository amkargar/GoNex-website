Gonex is a backend framework you **add to your own Go application**. Start with a small HTTP application, then build an HTML website or connect a frontend to your API. You do not need to modify the framework repository to use it.

## Start building

1. [Install the package](/docs/main/installation/) in a new or existing Go module.
2. [Run your first application](/docs/main/quick-start/) with a complete `main.go` and a typed JSON endpoint.
3. [Build a website](/docs/main/building-websites/) with HTML templates, CSS and a JSON API.
4. [Connect Nuxt, Vue or another frontend](/docs/main/frontend/) when you want a separate frontend application.
5. [Deploy your application](/docs/main/deployment/) as a Go service.

## Two documentation paths

**Build with Gonex** is the main documentation: installation, project setup, websites, APIs, modules, databases and deployment. It is for application developers.

**[Contribute to Gonex](/docs/main/contribute/)** explains how to fork the framework, run its tests, change its internals and prepare a contribution. It is for framework developers.

## Pick your project shape

| You want to build | Start here |

## Version status

These guides target the reviewed `main` snapshot. Gonex has no published release yet. The install guide pins a real source commit and explains the resulting Go pseudo-version. The documentation version selector is independent of your application's HTTP API version. See [release status](/docs/main/release/) before choosing a production dependency.
