# API consumer example

Use Go 1.27.2. `api/` is a separate consumer Go module generated by the CLI and extended with a users JSON API. No framework clone or local replace is required. Its exact handwritten source blocks appear in the Build a REST API guide.

```sh
cd api
go mod tidy
go tool gonex check
go tool gonex run
```

POST /api/users creates a user; GET /api/users lists users; GET /api/users/{id} retrieves one. Storage is memory-only. HTTP tests cover creation, empty/list results, validation, strict JSON, duplicate email, not found and OpenAPI. Request/lifecycle logging uses the generated config.
